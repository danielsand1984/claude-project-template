# Node CLI Skeleton

Commander-based CLI in TypeScript. Compiles to a single shebanged `bin/{{project_name}}.js`.

## Layout

```
src/
├── cli.ts             # Entry point — wires commands to the runtime
├── commands/          # One file per top-level command
│   └── hello.ts
└── lib/               # Pure-logic helpers
bin/
└── {{project_name}}.js    # Generated by build; do not edit
package.template.json
tsconfig.json
tests/
└── hello.test.ts
```

## During init

- Rename `{{PROJECT_NAME}}` / `{{project_name}}` to your slug (kebab-case).
- Rename `package.template.json` → `package.json`.
- Choose distribution: `npm publish`, `npx`, or `npm link` for local dev.

## Dev commands

```bash
npm install
npm run dev -- hello
npm test
npm run build && ./bin/{{project_name}}.js hello
```
