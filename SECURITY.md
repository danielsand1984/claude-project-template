# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for security vulnerabilities. Instead, email **{{AUTHOR_EMAIL}}** with:

- A description of the issue and its impact.
- Steps to reproduce, including any code or commands needed.
- Your name + affiliation (optional, for credit in the changelog).

You can expect:
- An acknowledgment within 48 hours.
- A first assessment within 7 days.
- A coordinated disclosure timeline if confirmed.

## Supported versions

Only the latest `main` branch receives security fixes during the initial development phase. We will update this section when we cut release branches.

## Security non-goals

This project does not currently:
- Run on public infrastructure (review before deploying to a multi-tenant cluster).
- Undergo regular external penetration tests.
- Carry a bug bounty.

If you discover a critical vulnerability and disclosure-coordination matters, we appreciate a 90-day embargo while we ship a fix.
